# 03: 切换根目录并扫描快照历史

**What to build:** 玩家可以在资源管理器里整理或复制快照，再通过切换根目录或刷新查看当前目录中的快照。

**Blocked by:** 02 · 创建并查看快照

**Status:** ready-for-agent

## 验收条件

- [ ] 切换根目录、点击「刷新」或重新选中游戏时扫描当前根目录的直接子目录，列表仅显示通过快照标识校验的目录。
- [ ] 手动复制完整快照目录后选择新根目录，列表显示该目录中可识别的快照。切换只更新配置与历史，保留用户复制前后的文件。
- [ ] 从当前根目录移出快照后，刷新即可从历史移除该行。普通目录照常占用其对应编号。
- [ ] 已有游戏切换根目录后延续编号并避开目标目录的占用。移除游戏配置前请求确认，保留磁盘快照。重新添加并选择旧根目录时识别历史，从最大已占用编号加一开始，空目录从 `0` 开始。
- [ ] 通过共享 Rust 应用层接口验证跨目录复制、外部移出、普通目录编号占用、切换根目录和重新添加游戏。
