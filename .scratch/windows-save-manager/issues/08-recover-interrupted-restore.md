# 08: 启动时处理意外中断的恢复

**What to build:** 恢复过程中应用意外退出后，玩家可以在下次启动时确认撤回，并看清何时能继续操作。

**Blocked by:** 07 · 恢复存档并撤回失败的替换

**Status:** ready-for-agent

## 验收条件

- [ ] 启动时识别未完成的恢复，并提示用户确认是否尝试撤回。处理完成前暂停受影响游戏的快照操作。
- [ ] 确认后根据已记录的进度和副本位置撤回。成功后重新开放该游戏的快照操作。撤回失败时保留副本并显示路径。
- [ ] 通过共享 Rust 应用层接口模拟重启并验证待处理状态、暂停和撤回后恢复操作，从 GUI 检查启动提示。
