# 02: 创建并查看快照

**What to build:** 玩家手动保存所选游戏的多个追踪项，并在快照历史中找到这次完整保存。

**Blocked by:** 01 · 添加、编辑和切换游戏配置

**Status:** ready-for-agent

## 验收条件

- [ ] 只在点击「创建快照」时开始保存。每项内容以原文件名或目录名放在快照顶层，目录内部结构原样保留。
- [ ] 编号按游戏独立分配，从 `0` 起算，重启后延续。留空用纯编号，填写名称则用「编号-名称」。名称支持中文和空格，去除首尾空白，并提示 Windows 无效名称。
- [ ] 检查 Windows 下的顶层原名冲突、标识文件保留名称、追踪路径相互包含及与快照根目录重叠。遇到符号链接或目录联接时停止并显示具体路径。
- [ ] 写入唯一快照标识、创建时间和恢复所需的原存档路径。全部内容复制到临时目录后才发布。路径缺失或复制失败时显示具体路径，历史中没有半成品，重试沿用待用编号。
- [ ] 避免使用当前根目录中已占用的编号，包括由普通目录占用的编号。快照历史按创建时间从新到旧显示编号、名称和创建时间。
- [ ] 通过共享 Rust 应用层接口和临时目录验证混合追踪项、名称、编号、路径冲突和失败重试。
