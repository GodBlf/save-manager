# 06: 将快照移到 Windows 回收站

**What to build:** 玩家可以确认删除一份快照，并在误删时通过 Windows 回收站找回。

**Blocked by:** 02 · 创建并查看快照

**Status:** ready-for-agent

## 验收条件

- [ ] 确认窗口标明待删除的快照。取消后目录和历史保持原样。
- [ ] 确认后把快照目录移入 Windows 回收站并更新历史。之后创建快照时继续递增，已删除的编号不会重新分配。
- [ ] 目标位置不支持回收站时显示错误并保留快照。
- [ ] 通过共享 Rust 应用层接口验证删除后编号延续，在 Windows 上验证回收站和回收站不可用的行为。
