# 05: 修改快照名称

**What to build:** 玩家能为快照换一个名称，同时用原编号继续识别它。

**Blocked by:** 02 · 创建并查看快照

**Status:** ready-for-agent

## 验收条件

- [ ] 改名只输入名称，例如输入 `A次要` 后将 `0-A重要` 改为 `0-A次要`。
- [ ] 创建和改名共用名称校验。清空名称后目录名只保留编号，无效名称导致界面提示。
- [ ] 成功后历史显示新名称，原编号、快照标识及存档内容可以继续使用。改名失败时保留原快照并报告错误。
- [ ] 通过共享 Rust 应用层接口验证改名、清空名称和名称校验。
