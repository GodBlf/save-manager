# 01: 添加、编辑和切换游戏配置

**What to build:** 启动 Windows 桌面应用后，玩家可以在左侧管理游戏列表，并在右侧查看和编辑所选游戏的配置。

**Blocked by:** 无，可立即开始

**Status:** ready-for-agent

## 验收条件

- [ ] 使用 Rust 和 egui / eframe 实现可启动的 Windows GUI。玩家可添加多个游戏配置并在左侧切换，右侧只显示所选游戏的配置。
- [ ] 每个游戏可添加、编辑或移除多条追踪路径，支持文件和目录，并可设置当前快照根目录。
- [ ] 两个游戏配置选中同一个 Windows 目录时，界面提示冲突并保留有效配置。
- [ ] 配置保存在 Windows 应用数据目录，重启后可以重新选择并查看已有配置。
- [ ] 通过 GUI 共用的 Rust 应用层接口验证多游戏配置、目录独占和重启后的持久化。
