# 07: 恢复存档并撤回失败的替换

**What to build:** 玩家可以将所选快照恢复到原存档路径。一次恢复中途失败时，应用尝试找回刚刚被替换的内容。

**Blocked by:** 02 · 创建并查看快照

**Status:** ready-for-agent

## 验收条件

- [ ] 确认窗口列出快照创建时记录的目标路径。取消时保留目标原样。编辑游戏配置后，旧快照的恢复目标仍以原记录为准。
- [ ] 确认后完整替换目标目录，恢复结果与快照一致。恢复遇到符号链接或目录联接时停止并报告路径。
- [ ] 写入前记录恢复进度和临时副本位置，并临时保留目标的原内容。全部成功后清理临时副本。
- [ ] 恢复中途失败时撤回已完成的替换。撤回失败时保留临时副本并显示位置。
- [ ] 通过共享 Rust 应用层接口验证旧路径、完整替换、中途失败和撤回失败，另从 GUI 核对确认窗口列出的目标。
